# Исходные материалы «Читалки»

Приватный репозиторий исходников: [Artmalinkov/Chitalka](https://github.com/Artmalinkov/Chitalka), основная ветка `main`. Репозиторий начинается с этой папки: `app/` содержит приложение и отдельные проверки, `tools/` — сценарии сборки и запуска. Книги, личные конспекты, снимки эмулятора, временные файлы, APK, настройки конкретного компьютера и ключи подписи исключены из Git. Полная локальная папка проекта сохраняется отдельно.

Текущая версия — **0.1.7**: FB2 и ручные карточки бумажных книг, прогресс по страницам, обложки, конспект со свободными структурными типами и вложенностью, мысли, герои, цитаты и экспорт Markdown. Первичная проверка бумажного режима выполнена в эмуляторе.

Для сборки нужны Android SDK (платформа 36 и Build Tools 36.0.0) и JDK 17 или новее. Запустите `Собрать Android.cmd` либо передайте свои пути сценарию `tools/Build-Android.ps1` через параметры `-SdkPath`, `-JavaHome`, `-BuildRoot`. Gradle пока не используется. APK появляется в соседней папке `_приложение`; для обновления существующей установки нужен её прежний ключ подписи, который хранится отдельно от репозитория.

Некоторые проверки FB2 используют локальный пример книги «Граф Монте-Кристо»; книга и личный конспект в репозиторий не входят. Папки, упомянутые ниже как примеры и результаты проверок, относятся к полной локальной копии проекта.

В этой папке хранятся код приложения, настройки сборки, материалы разработки и вспомогательные сценарии. Текущее расположение от корня проекта: `Приложение/Android/_исходник/`.

- `Примеры/` — исходный FB2 и личный Markdown-конспект владельца, а также их разбор. Не менять пользовательские примеры автоматически и не включать книгу в распространяемое приложение.
- `tools/` — сценарий запуска Android-эмулятора и состояние установки окружения.
- `app/src/main/` — исходники первого Android-приложения: интерфейс, разбор FB2, локальная библиотека и записи.
- `app/src/androidTest/` — отдельные проверки на устройстве; в пользовательский APK не включаются.
- `Проверки/` — результаты испытаний и снимки интерфейса.

Первая сборка: **0.1.0**, 26.10.2026. В **0.1.2** добавлены абзацы с красной строки без промежутков, выравнивание текста по ширине без переноса слов. Для установки и открытия в эмуляторе используйте `Запустить Читалку.cmd`, для повторной сборки — `Собрать Android.cmd`. Порядок работы и ограничения описаны в [Сборка и проверка.md](Сборка%20и%20проверка.md).

Готовые APK и информация об их версиях размещаются в соседней папке `_приложение`. Летопись, план, требования и опросник остаются в корне проекта.

Android SDK размещается отдельно в `D:\Android\Sdk`, чтобы не смешивать многогигабайтное окружение с исходниками приложения. Эмулятор Android 16 установлен и проверен. Виртуальный телефон открывается файлом `Запустить эмулятор.cmd`; подробности — в [Android-окружение.md](Android-окружение.md).
